# Crisis Nexus Advisory Website

A static, responsive website designed for GitHub Pages.

## Files
- `index.html` — homepage
- `projects.html` — projects and engagement areas
- `contact.html` — contact page
- `styles.css` — site design and responsive styling
- `script.js` — mobile menu, animations and cursor effect

## Publish on GitHub Pages
1. Upload all files to the root of your `Crisis-Nexus-Advisory` repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`, then save.
5. Your site will appear at `https://aokello3300.github.io/Crisis-Nexus-Advisory/`.

## Important edits before launch
- Replace `contact@crisisnexusadvisory.com` in `contact.html` with your real email.
- The projects page intentionally describes illustrative engagement types, not completed client work.
- Add your final domain later through GitHub Pages settings.
